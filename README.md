# FlowForge Team Starter Pack

This pack contains the eight required living project documents plus the team plan and role-specific prompts.

## Add to the GitHub repository
1. Extract this ZIP.
2. Copy the `docs/` folder into the repository root.
3. Copy `TEAM_PLAN_AND_PROMPTS.md` and `README.md` into the repository root (or `/project-planning/` if the team prefers).
4. Aditya opens a documentation-only PR to `dev`.
5. All four team members review and approve the docs. Merge this PR before feature coding begins.
6. Start implementation only after all eight docs exist in the shared repository and the team has agreed the `flow.md` contract.

## Living-document update policy
The files are not static templates. Update relevant sections and append dated progress-log entries throughout development. Follow `docs/rules.md` and the daily update process in `TEAM_PLAN_AND_PROMPTS.md`.
